# Total Tools visual direction

Selected reference: candidate B from hosted 12ui run `crt-78e6badbcf8088781274e0ea365aa35b74141629`.

Four candidates were generated and inspected. B established the neutral shell, green/yellow brand accents, transaction-first workspace and focused checkout panel. The selected original is retained as `selected-reference.png`.

12ui expanded the reference into eight operations screens and five supporting screens, with responsive HTML exports used as design references. Generated mockups were not substituted for production data or business actions. Automated prototype validation in those generated exports stopped because the service's managed Chromium executable was unavailable; no prototype validation success is claimed.

The complete generated references, exported HTML, and original run output remain on the [evidence branch](https://github.com/chavzwill/pos_system/tree/evidence/total-tools-ui/docs/ui-design/evidence). Temporary recovery controls, diagnostic output and image transport copies are excluded from the product PR.

Production integration uses existing certified modules, a new shell, shared presentation tokens, and a workspace host. All execution and browser checks use GitHub Actions. Vercel automatic Git deployment remains disabled.

Implementation alignment review and release evidence are tracked in the PR; no deployment approval is implied by a passing design check.
