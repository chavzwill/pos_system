# Commercial document design previews

These are **fictional samples**, generated from the commercial POS renderer to demonstrate visual appearance. The example company, customer, supplier, contacts, document numbers and amounts are illustrative—not actual business records.

- `quotation.png` / `quotation.pdf`: quotation with customer details, line items, tax, discount, validity and customizable terms.
- `purchase-order.png` / `purchase-order.pdf`: approved purchase order with supplier and receiving information, tax, terms and recorded order total.
- `sales-invoice.png` / `sales-invoice.pdf`: completed sales transaction invoice with itemization and payment context.

The printed examples use `public/commercial-documents.js` and `public/commercial-documents.css`; each sample was verified to fit on one A4 page. Real documents must always use saved POS records and the buyer's uploaded company branding. Do not treat these samples as financial evidence.
