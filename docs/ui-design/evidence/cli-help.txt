--output html selects the engine before dispatch. Auto uses local Codex when
available; --model, --width, --responsive-quality, --origin, --api-key, and
--idempotency-key select API and cannot be used with --engine codex. Local work
is identified by its saved run directory; use 12ui resume <local-run-dir> to recover.
--engine codex or api makes the choice explicit. Local HTML contains editable HTML/CSS and assets,
without LayerDoc. API HTML uses fused LayerDoc and responsive HTML conversion.
New local runs use native images on your Codex sign-in. --image-backend external
opts in to your own OpenAI key (OPENAI_API_KEY alone never does) and requires the
key before planner execution. Explicit image choices and saved runs remain fixed.
Local failures never silently retry through the API. Local resume uses recorded
settings and does not accept --out-dir, --timeout-ms, --output, or --out.
Improve --apply supports page scope only and capture/draft/pick source stages;
the site, branch, conversion, and planning options above belong to hosted kits.

`draft` keeps every dispatch request in this foreground process, then returns
with generation server-side; `12ui next <run-dir> --wait` polls, repairs only
recorded slots that never started, and downloads the PNGs. `branch execute`
and `branch resume` stay foreground through their network work. A second shell
can use `12ui next <run-dir>` to report what is moving.

`branch execute --prototype` runs after `--convert html` and buys one cheap
four-way interaction-label call per screen. Standalone `prototype <run-dir>`
defaults to local deterministic interactions; `--labels 12ui` explicitly buys
hosted interaction labels. `--labels workflow --workspace <directory>` prepares
exact DOM-bound local label operations and returns awaiting_labels; execute/register
them through workflow, then repeat prototype to consume their results without inference.
Add `--polish` explicitly to run the
retained deterministic polish rules before runtime verification; it is opt-in.

Hosted work accepts --origin <url> and --api-key <key> (defaulting to
TWELVE_UI_ORIGIN / TWELVE_UI_API_KEY, then `12ui auth login`). Local next, resume,
and export do not accept hosted authentication flags. --quiet suppresses progress. Omit
--client to target every supported CLI installation. `12ui <command> --help`
prints any command in full, including the forms this summary leaves out:
`convert package --template`, `skill print`, `skill remove`.
`12ui scene --help` lists the local Three.js scene tools and `12ui workflow --help` the workflow commands.
